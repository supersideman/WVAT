# 个人 AI 便携控制终端（WVAT）

本科毕业设计 · 大连大学 自动化

> 戴在手腕上的便携控制终端：**点屏幕或说话 → 意图上行 → 电脑执行 → 结果回到屏幕**。
> 硬件基于开源智能手表工程二次开发（FryPi / STM32F411 + LVGL 8.2 + FreeRTOS）。

**它不是智能手表，是戴在手上的 AI 遥控器。**

## 快速开始

### ① 手表端：编译烧录

```
用 Keil 打开： 01_firmware/keil/LVGL_template/MDK-ARM/LCD.uvprojx
F7 编译 → F8 下载（ST-Link）
```

### ② PC 端：启动网关（**必须由你自己双击启动**）

```
双击：02_gateway/start_gateway.cmd
```

它会自动找到 CH340 串口并以真执行模式启动。

> ⚠️ **为什么必须自己启动**：由其他高权限/沙箱进程代启时，Windows 会挡住
> 按键注入（`SendInput` 返回成功但输入进不了桌面），表现为"播放/暂停没反应"。
> 详见 [问题与尝试记录 §4.2](04_docs/问题与尝试记录.md)。

### ③ 使用

```
锁屏 → 上滑解锁（拖过屏幕 1/3）→ 主界面
主界面： ♪ 播放/暂停   ▶| 下一首   田字格（更多）   麦克风按钮
抽屉页： 我困了 / 音量+ / 音量− / 打开资料 / 查状态 / 语音
        点一下 → 顶部条出现该意图图标，右侧圆点：绿=成功、红=失败、无点=等待（3 秒超时）
```

## 开源与合规

本项目基于以下开源工程二次开发，遵循 **GPL-3.0**：

- 炸鸡开源硬件《嵌入式STM32+RTOS实战教程，手搓智能手表》（BV1pfRCBPEdC）—— 硬件设计与 Keil 工程模板
- LVGL 8.2 —— 图形库
- FreeRTOS —— 实时内核

**本课题的贡献**：意图协议与双通道路由设计、纯图元图标系统、跟手滑动解锁交互、
关键路径可验证性（动作回读 + 超时守卫）、以及上述问题的定位与修复。
