> 依据：用户实拍 + 作者仓库 `1.hardware/摄像头+LCD扩展板前视图.jpg` 与 `SCH_exCam_2024-04-09.pdf`

| 位置 | 形态 | 丝印 | 判断 |

## 八、官方 pin map 的"占用 / 空闲"判定

> 图：[frypi-pin-map.jpg](hardware/frypi-pin-map.jpg)（作者手册原图，已存本地）
> 读法：**每个脚如果挂了彩色功能框 = 被占用；只有蓝色脚名 = 空闲**。

### 已占用的（8 类外设，14 个脚）

| 外设 | 引脚 | 图上标签 |
|---|---|---|
| LCD 背光 | PA15 | `LCD BL` |
| LCD 数据/命令 | PC12 | `LCD DC` |
| LCD 片选 | PD2 | `LCD CS` |
| LCD 复位 | PB4 | `LCD RST` |
| LCD 时钟 | **PB3** | `SPI SCK` → `LCD CLK` |
| LCD 数据 | **PB5** | `SPI MOSI` → `LCD SDA` |
| 触摸 SCL | PB6 | `I2C1 SCL` → `TP SCL` |
| 触摸 SDA | PB7 / PB8 / PB9 | 图上三处都标了 `TP SDA`（见下方说明）|
| USB 转串口 TX | PA9 | `USART1 TX` |
| USB 转串口 RX | PA10 | `USART1 RX` |
| USB D− | PA11 | `USB DM` |
| USB D+ | PA12 | `USB DP` |
| 用户按键 | PA0 | `KEY`（也叫 `EXTIO`）|
| 用户 LED | PC13 | `LED2` |

**预留但未占用**：PA8 = `I2C3 SCL`（丝印 `MLX SCL`）、PC9 = `I2C3 SDA`（`MLX SDA`）
—— 作者留给热成像模块，板上没有连接任何器件，**可以自由使用**。
PA2 标了 `PWM CH3`，这是**能力提示**（可用作 PWM），不是被占用。

### 空闲的（无任何标签，共 25 个）

| 排针 | 空闲引脚 |
|---|---|
| 左排 | PC6、PC7、PC8、PC10、PC11（+ PA8/PC9 见上）|
| 右排 | **PB14、PB15、PB12、PB13**、PB2、PB10、PB0、PB1、PC4、PC5、PA6、PA7、PA4、PA5、PA3、PA1、PC2、PC3、PC0、PC1 |

**结论：I2S2 需要的 PB12(WS) / PB13(CK) / PB15(SD) 三根全部空闲，且图上没有挂任何功能框。**

### ⚠️ 一处图面歧义（不影响本项目）

图上 `TP SDA` 同时标在 PB7、PB8、PB9 三处。核心板背面丝印写的是 `TP_SDA=PB8`，
而 `I2C1 SDA` 按 STM32 映射应为 PB7。三处标注只能有一个是对的，
**实际以原理图或量线为准**；本项目不使用这三个脚，暂不深究。

## 九、扩展板（exCam）是否占用 PB12/PB13/PB15 —— 用嘉立创 EDA 版面确认

用户在嘉立创 EDA 打开作者的 `PCB_exCam` 工程（GPL 3.0 开源），逐脚查看铜箔走线：

| 焊盘 | 是否有走线引出 |
|---|---|
| PB15 / PB14 | 无 |
| **PB13 / PB12** | **无**（孤立的母座焊盘）|
| PB10 / PB2 | 有（红色走线 + 过孔）|
| PB1 / PB0 / PC5 / PC4 / PA7 / PA6 | 无 |
| PA5 / PA4 | 有（过孔）|

**推论**：扩展板只机械地"接住"核心板的针，电气上**没有使用 PB12/PB13/PB15**。
因此在这三处焊线不会与扩展板上的任何电路冲突，
焊接点就选在**核心板背面的对应焊点**（拆下扩展板即可操作），焊完再插回去。

配套证据（扩展板 BOM 仅 10 项）：
`U3/U4` = 2×13 母座、`H1` = 2×9 母座（**摄像头 DVP 接口**：3V3+GND+SCCB+VSYNC/HREF/PCLK/XCLK+D0~D7 ≈ 18 根）、
`H2` = 4P 母座（I2C 引出 `3V3/GND/SCL/SDA`）、`X3` = `AFC07-S18ECA-00`（18P FPC）。

⚠️ 核心板的屏幕座是 `AFC01-S18FCA-00`，扩展板是 `AFC07-S18ECA-00`：
同是 18P，但 **F/E 后缀通常表示接触面方向不同**，屏幕排线大概率不能直接互换插，
**不要硬插**。

## 十、扩展板 2×9 接口的**实测**映射（2026-11-17 万用表通断测得）

之前对 2×9 的用途只是推测（怀疑是摄像头 DVP），实际用万用表逐个量过之后确认：
它是**核心板右排下半段 IO 的引出**，并且带电源。

| 列（左→右） | 上排 | 下排 |
|---|---|---|
| 1 | **GND** | **3V3** |
| 2 | PB2 | **PB10** |
| 3 | PB0 | PB1 |
| 4 | PC4 | PC5 |
| 5 | PA6 | PA7 |
| 6 | PA0 | **PA5** |
| 7 | PC2 | **PA3** |
| 8 | PC0 | PA1 |
| 9 | （空孔/无连接）| **PC3** |

**对照官方 pin map 核对**：下排正好是核心板右排那一列从 `PB10` 到 `PC3` 连续 8 根；
上排是相邻一列抽出来的 7 根。完全自洽。

### 由此得到的结论

| 用途 | 能否直接用 2×9 |
|---|---|
| I2S2 备用脚 CK=**PB10** | ✅ 下排第 2 孔 |
| I2S2 备用脚 SD=**PC3** | ✅ 下排第 9 孔 |
| I2S2 主用脚 PB12/PB13/PB15 | ❌ 都不在 2×9 上 |
| **麦克风供电 3V3 / GND** | ✅ 下排第 1 孔 / 上排第 1 孔 |
| 蓝牙 RX=**PA3** | ✅ 下排第 7 孔 |
| 蓝牙 TX=PA2 | ❌ 需飞线 |
| 超声波/ADC 等模拟输入 | ✅ PA5/PA6/PA7、PC4/PC5 等 |

### ▶ 于是最省事的麦克风接法（只需飞 1 根线）

```
INMP441 SCK → 2×9 下排第 2 孔 = PB10
INMP441 SD  → 2×9 下排第 9 孔 = PC3
INMP441 VDD → 2×9 下排第 1 孔 = 3V3
INMP441 GND → 2×9 上排第 1 孔 = GND
INMP441 L/R → 就近接 GND（选左声道）
INMP441 WS  → 飞线到 PB12（唯一需要焊的一根）
```

固件已支持 4 套引脚组合自动探测（含 “WS=PB12 + CK=PB10 + SD=PC3” 的混合组合），
烧进去就会打印实际生效的那一套。
