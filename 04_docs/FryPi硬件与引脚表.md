| 16 | 其余 | 0603 电容电阻若干、F0805 保险丝 |

**BOM 里没有的东西（重要）**：

- **没有蓝牙、没有 WiFi、没有任何射频模块**
- **没有任何传感器**（无 IMU / 无温湿度 / 无心率）
- **没有电池、没有充电 IC**（USB 供电）
- **没有 DAC**（F411 本身无 DAC，也没有外挂）
- **没有 SD 卡槽**（16MB Flash 是唯一的板载存储）

## 三、已被占用的引脚（来自模板工程 GPIO 配置 + 丝印）

| 用途 | 引脚 |
|---|---|
| LCD（SPI1，单向写） | **PB3**=SCK、**PB5**=MOSI、**PC12**=DC、**PD2**=CS、**PB4**=RST、**PA15**=BL |
| 触摸（I2C1） | **PB6**=SCL、**PB8**=SDA |
| USB-TTL（USART1） | **PA9**=TX、**PA10**=RX |
| USB FS | **PA11**=DM、**PA12**=DP |
| 用户按键 / LED | **PA0**=KEY、**PC13**=LED2 |
| RTC 晶振 | PC14/PC15 |
| HSE 晶振 | PH0/PH1 |

## 四、空闲且已引出（可外接）

| 外设机会 | 引脚 | 说明 |
|---|---|---|
| **I2S2（数字麦克风）** | **PB12**=WS、**PB13**=CK、**PB15**=SD | ✅ 三根全空闲，本项目主线 |
| I2C3 | **PA8**=SCL、**PC9**=SDA | 丝印标 MLX SCL/SDA，作者本留给热成像；可接 MPU6050/AHT20 等 |
| USART2 | **PA2**=TX、**PA3**=RX | HC-05 蓝牙 / ESP8266 |
| ADC | PA1–PA7、PC0–PC5、PB0/PB1 | 模拟量采集 |
| PWM | 多个 TIM 通道落在 PA/PB/PC 上 | 舵机/蜂鸣器/振动马达/背光 |
| 普通 GPIO | PB0/PB1/PB2/PB9/PB10/PB14、PC0–PC11 剩余 | — |

**I2S3 不可用**：CK/SD/WS 落在 PB3/PB4/PB5，全被 LCD 占用。

## 五、待实物确认项

1. **排针是否已焊**（作者渲染图里是焊好的；实物以眼为准）。
   若 `PB12/PB13/PB15` 只有焊盘没焊针 → 需要焊接或免焊测试钩。
2. **你的板子是否 V1.1**：后视图丝印是 `FryPi-F411DevKit V1.1`，实物核对一下。
3. **W25Q128 的 CS/MISO 引脚**：BOM 确认板上有这颗 Flash，但
   ① 作者软件里**没有 W25Q 驱动**（仓库全局搜不到）；
   ② 原理图 PDF 是矢量图，文字抠不出来。
   → 若要用这块 16MB Flash 做持久化，需实物对照原理图或量线确认。
