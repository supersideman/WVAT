# 工作室焊接清单（一次做完）

> 目标：接**麦克风 INMP441 + 蓝牙模块**——只需飞 **PB12 + PA2** 两根线，其余全部从扩展板 2×9 取
> 板子：FryPi-F411DevKit V1.1 + CAM 扩展板 + 屏幕
> 依据：`FryPi硬件与引脚表.md` §十（万用表实测的 2×9 映射）；固件 `user_i2s.c` 的 4 套引脚组合
>
> ⚠️ 本文早期版本写的是"飞 PB12/PB13/PB15 三根"，**已作废**：CK/SD 走 2×9 的 PB10/PC3 即可。

---

## 一、带什么去

| 物件 | 说明 |
|---|---|
| 核心板 + 扩展板 + 屏幕 | 全部带上，别只带一块 |
| **杜邦线（公对母）** | 至少 6 根。2×9 是母座 → 公头插进去，母头套模块的针 |
| **细导线** | 飞线用，比杜邦线细一档最好（0.3~0.5mm 单芯） |
| 2×9 母座 / 4P 母座 | 如果工作室没有，自带（你已有的那个 2×9 可以 reuse，清理后重焊）|
| **助焊剂** | 关键！没有它就是连锡的根源 |
| 吸锡带 或 多股铜线 | 清连锡用 |
| 万用表 | 焊完必须测 |
| 手机 | 拍焊点，回来给我看 |
| 这份清单 | 打印或手机打开 |

## 二、焊接顺序（从易到难）

### 第 1 步（必做·先测）：确认 2×9 没有连锡

```
1. 万用表通断档：下排第 2 孔（PB10）与相邻孔 —— 必须【不响】
2. 下排第 9 孔（PC3）与相邻孔 —— 必须【不响】
3. 3V3 孔（下排第 1）与 GND 孔（上排第 1）—— 必须【不响】
```

**只有测出响了才需要清连锡**（涂助焊剂 → 350℃ 顺着两孔之间加热 → 吸锡带吸走）。
别再大面积重焊：这几个孔只在"有连锡"时才动，焊盘焊掉了就真麻烦了。

### 第 2 步（可选）：焊 4P 底座

扩展板左侧 `3V3 / GND / SCL / SDA` 那个 1×4 位置。**这次不做也行**——麦克风和蓝牙的供电都从 2×9 取。
以后要接 I2C 传感器（MPU6050 / AHT20）时再焊。

### 第 3 步：飞两根线（唯一要动烙铁的地方）

焊在【扩展板背面】的母座焊盘上（不是核心板！这三个 PA/PB 焊盘在扩展板上是悬空的，EDA 已确认）。

| 飞线 | 焊到哪个焊盘 | 另一头接谁 |
|---|---|---|
| **PB12** | 2×13 母座**倒数第 2 行**、靠板边那列 | 麦克风 **WS** |
| **PA2** | 2×13 母座**第 8 行**、靠板边那列 | 蓝牙 **RXD** |

**怎么数（别信"左排/右排"的文字，背视图会镜像）：**

```
用万用表找到 GND|GND 那一行当锚点，从 GND 端往上数：
  第 13 行  GND | GND     ← 锚点
  第 12 行  5V  | 3V3
  第 11 行  PC1 | PC0
  第 10 行  PC3 | PC2
  第  9 行  PA1 | PA0
  第  8 行  PA3 | PA2     ← PA2 在这行（内列 PA3、外列 PA2）
  ...
  第  2 行  PB13| PB12    ← PB12 在这行（内列 PB13、外列 PB12）
  第  1 行  PB15| PB14
```

**焊前验证焊盘选对了**：该焊盘与相邻焊盘【不响】、与 2×9 任何一孔【不响】——悬空正是它的特征。

**焊接要点**：

| 要点 | 说明 |
|---|---|
| 线先镀锡 | 线头点焊锡，变银亮 |
| 焊盘先补锡 | 焊盘上先上一点锡，再贴线 |
| 每根 ≤2 秒 | 超时会烫化塑料母座 |
| 线长 12~15cm | 太长 I2S/串口都会串扰 |
| **贴标签** | 胶带+记号笔写 WS / BT-RX，否则回来分不清 |
| 打热熔胶 | 固定线根，防止反复弯折断线 |

### 第 4 步：插 2×9 的杜邦线（不用焊）

需要**公对母**杜邦线（2×9 是母座，公头插进去，母头套模块的针）。

| 2×9 孔位 | 引脚 | 接到 |
|---|---|---|
| 上排第 1 | GND | 麦克风 GND + 蓝牙 GND（共用） |
| 下排第 1 | 3V3 | 麦克风 VDD + 蓝牙 VCC（共用） |
| 下排第 2 | PB10 | 麦克风 **SCK** |
| 下排第 7 | PA3 | 蓝牙 **TXD**（模块发 → MCU 收） |
| 下排第 9 | PC3 | 麦克风 **SD** |
| 上排第 9 | 空孔 | 别插 |

**INMP441 六根线，一根都不能漏：**

| INMP441 | 接到 | 备注 |
|---|---|---|
| VDD | 3V3 | ⚠️ **绝不能接 5V** |
| GND | GND | |
| **L/R** | **GND** | 接地=左声道。固件只读左声道，**这是最容易漏的一根** |
| SCK | PB10 | 位时钟 |
| SD | PC3 | 数据 |
| WS | PB12 | 飞线过来 |

**蓝牙模块 HC-05（6 针：VCC / GND / TXD / RXD / STATE / EN，针序以丝印为准）：**

| 模块 | 接到 | 备注 |
|---|---|---|
| VCC | 3V3（先试） | 模块自带 3.3V LDO，可吃 3.6~6V。**若闪屏/反复掉线，改接 2×13 母座第 12 行的 5V 焊盘**（要多飞一根线）|
| GND | GND | |
| TXD | PA3（下排第 7 孔） | **交叉接**：模块 TX → MCU RX |
| RXD | PA2（飞线） | 模块 RX → MCU TX |
| STATE | 不接 | 高电平=已连接，想点亮 LED 指示再引 |
| EN / KEY | 不接 | 悬空即正常通信模式；拉高再上电才进 AT 模式 |

**HC-05 专有的四个坑**：

| 坑 | 说明 |
|---|---|
| **默认波特率 9600** | HC-05 出厂就是 **9600 8N1**，而 USART1 跑 115200。写 USART2 驱动时**别照抄 USART1 的参数**，否则收到一堆乱码 |
| **AT 模式另开一个波特率** | 只有把 EN/KEY 拉高再上电才进 AT 模式（**38400** 8N1），用来改名字/波特率/配对码。正常通信模式下发 AT 指令是无效的，这是最常见的误判 |
| **默认是从机** | 要从 PC/手机主动连它。Windows 蓝牙里配对（配对码一般 `1234` 或 `0000`），成功后**会冒出两个 COM 口**，用带"出方向/Outgoing"的那个 |
| **TXD/RXD 是 3.3V 逻辑** | 与 F411 的 PA2/PA3 电平相同，可以直接连，不需要电平转换；**千万不要把 5V 灌进 TXD/RXD** |

> 想在下烙铁前先验证模块是好的：拿手机装个"蓝牙串口助手"，配对 HC-05 后发几个字符，
> 能收到回显就说明模块没坏——这一步不需要固件。

> ⚠️ **早期版本这里写"PA2/PA3 都在 2×9 第 6 行，可以直接插"——那是错的。**
> 实测第 6 列下排是 PA5，PA3 在第 7 列；**PA2 根本不在 2×9 上，必须飞线**。

> ⚠️ **蓝牙现在接上也还不能用**：固件 `user_link.c` 只驱动 USART1（板载 CH340），
> 整个 User/ 目录没有任何 USART2 代码。接好只是硬件就绪，要真用蓝牙当链路，
> 得另加一路 USART2 收发（并处理 SPP 粘包/半包）。**建议先调通麦克风，再动固件。**

## 三、焊完必须测的几项（万用表通断档）

| 测什么 | 期望 |
|---|---|
| `3V3` 孔 ↔ `GND` 孔 | **不响**（响了 = 电源短路，绝对不能上电）|
| PB12 线头 ↔ 背面 PB12 焊盘 | 响 |
| PA2 线头 ↔ 背面 PA2 焊盘 | 响 |
| PB12 线 ↔ PA2 线 | **不响**（两根不能短在一起）|
| 下排第 2 孔 ↔ 相邻孔 | 不响（PB10 不能短到邻居）|
| 下排第 9 孔 ↔ 相邻孔 | 不响（PC3 同上）|

**全部通过才通电。** 通电后先摸 `U5`（3.3V 稳压，SOT-23 那个小芯片）——**发烫立刻拔电**。

## 四、回来后的调试流程（我已准备好）

```powershell
# 1. 板子插 USB
# 2. Keil: F7 编译 → F8 下载
# 3. 跑串口监视（必须用随附的 Python 3.12，系统的 python 是 Store 空壳）
$py = Join-Path $env:USERPROFILE ".dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py "C:\Users\lisijie\Documents\deepseek-harness\default-workspace\WVAT\05_scripts\serial_monitor.py"
```

预期输出（这些字符串是固件 `user_i2s.c` 里写死的，逐字对应）：

```
[mic] 引脚组合：PB12 + PB10 + PC3 混合        ← 本次方案应有的结果
[mic] 自检开始，采 1 秒，请随便说句话
[mic] lvl: 00001353000000000000000000000000   ← 安静时 0/1，说话时 3/5/7/9
[mic] L: peak=4821 rms=312
[mic] R: peak=0 rms=0  frames=16128
[mic] OK：左声道有信号，接线正确
```

**判读表**：

| 现象 | 含义 |
|---|---|
| `引脚组合：PB12 + PB10 + PC3 混合` + `OK` | ✅ **本次接线成功** |
| `引脚组合：PB12(AF6) + PB10 + PC3 混合` + `OK` | ✅ 也算成功，只是 AF 走了另一套，固件已兜住 |
| `引脚组合：PB12/PB13/PB15 全 AF5` | 只有额外飞了 PB13/PB15 才会出现 |
| `引脚组合：PB9 + PB10 + PC3 全 AF6` | WS 接到 PB9 去了，不是 PB12 |
| `所有引脚组合都没数据：查 3V3/GND 供电…` | 供电没到 / SD 线没通 / L/R 没接 GND |
| `右声道有声、左声道无：L/R 接到了 3V3` | L/R 接错，改接 GND |
| `两声道都接近 0：查 SD 线、3V3/GND 供电` | SD 线没通，或供电没到 |
| `读取超时（采集中断）` | SCK（PB10）没通 |
| `PLLI2S 起振超时` | 时钟问题，基本不是接线的事 |

## 五、给工作室的一句话总结

> **两件事**：
> ① 万用表测 2×9 的 3V3/GND/PB10/PC3 四个孔，没有连锡、没有短路；
> ② 扩展板背面飞 **PB12 → 麦 WS**、**PA2 → 蓝牙 RXD** 两根线，贴标签。
>
> 其余全部用**公对母杜邦线**插 2×9，不用焊。全程用助焊剂，焊完测通断和短路。
