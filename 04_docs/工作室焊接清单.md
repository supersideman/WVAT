# 工作室焊接清单（一次做完）

> 目标：把扩展板 2×9 修好、补焊 4P 底座、飞线 PB12/PB13/PB15，回来直接调试
> 板子：FryPi-F411DevKit V1.1 + CAM 扩展板 + 屏幕

---

## 一、带什么去

| 物件 | 说明 |
|---|---|
| 核心板 + 扩展板 + 屏幕 | 全部带上，别只带一块 |
| **杜邦线（母对母）** | 至少 6 根 |
| **细导线** | 飞线用，比杜邦线细一档最好（0.3~0.5mm 单芯） |
| 2×9 母座 / 4P 母座 | 如果工作室没有，自带（你已有的那个 2×9 可以 reuse，清理后重焊）|
| **助焊剂** | 关键！没有它就是连锡的根源 |
| 吸锡带 或 多股铜线 | 清连锡用 |
| 万用表 | 焊完必须测 |
| 手机 | 拍焊点，回来给我看 |
| 这份清单 | 打印或手机打开 |

## 二、焊接顺序（从易到难）

### 第 1 步：修 2×9 的连锡

```
1. 涂助焊剂
2. 烙铁 350℃，顺着两孔之间轻轻加热
3. 用吸锡带（或多股铜线蘸助焊剂）吸走多余焊锡
4. 手机微距拍照，逐个确认没有连锡
5. 万用表通断档：相邻两孔之间必须【不响】
```

⚠️ **如果清理后铜箔掉了**（焊盘被焊掉）——立刻停手，别继续，回来告诉我换方案。

### 第 2 步：焊 4P 底座（扩展板左侧 `3V3 / GND / SCL / SDA`）

```
焊 1×4 母座，注意方向：3V3 在最上面，SDA 在最下面
焊完测：3V3 孔 ↔ 板上 3V3 排针  应导通
        GND 孔 ↔ 板上 GND 排针  应导通
```

这两个孔以后供麦克风/传感器取电，很方便。

### 第 3 步：飞线 PB12 / PB13 / PB15（最考验手稳，放最后）

```
焊在【扩展板背面】对应母座的焊盘上（不是核心板！）
   PB12 → WS   （右排第 2 行 左边）
   PB13 → SCK  （右排第 2 行 右边）
   PB15 → SD   （右排第 1 行 右边）

为什么焊扩展板：
  这三个焊盘在扩展板上是【悬空】的（EDA 里确认过没走线），
  焊上去等于直接接在核心板对应针上，而且焊盘大、周边空、好操作。
```

**焊接要点**：

| 要点 | 说明 |
|---|---|
| 线先镀锡 | 线头点焊锡，变银亮 |
| 焊盘先补锡 | 焊盘上先上一点锡，再贴线 |
| 每根 ≤2 秒 | 超时会烫掉焊盘（塑料座会化）|
| 从内往外焊 | PB12/PB13 靠内，先焊 |
| 线长 12~15cm | 太长 I2S 时钟会串扰 |
| **贴标签** | 用胶带+记号笔标 WS/SCK/SD，否则回来分不清 |
| 打热熔胶 | 固定线根，防止反复弯折断线 |

### 第 4 步（可选）：蓝牙模块飞线

```
HC-05  VCC → 5V 或 3V3（模块板一般自带稳压，接 5V 更稳）
       GND → GND
       TXD → PA3（核心板 USART2_RX）
       RXD → PA2（核心板 USART2_TX）
```

⚠️ 注意是**交叉接**：模块 TXD 接单片机 RX。
⚠️ PA2/PA3 也在 2×9 上（第 6 行），2×9 修好后可以直接插。

## 三、焊完必须测的三项（万用表通断档）

| 测什么 | 期望 |
|---|---|
| `3V3` 排针 ↔ `GND` 排针 | **不响**（响了 = 电源短路，绝对不能上电）|
| PB12 线 ↔ 核心板 PB12 针 | 响（导通）|
| PB13 线 ↔ 核心板 PB13 针 | 响 |
| PB15 线 ↔ 核心板 PB15 针 | 响 |
| 三根线之间两两互测 | **不响**（响了 = 短在一起）|
| 4P 的 3V3 ↔ 板 3V3 | 响 |

**全部通过才通电。** 通电后先摸 `U5`（3.3V 稳压，SOT-23 那个小芯片）——**发烫立刻拔电**。

## 四、回来后的调试流程（我已准备好）

```
1. 板子插 USB
2. Keil: F7 → F8
3. 跑串口监视：
     python WVAT\05_scripts\serial_monitor.py
4. 看输出：
     [mic] 引脚组合：PB12/PB13/PB15 (AF5 主用)     ← 说明主用脚通了
     或 PB9/PB10/PC3 (AF6 备用)                    ← 说明走的是备用脚
     [mic] lvl: 00013579530000                     ← 说话时数字变大
     [mic] L: peak=4821 rms=312
     [mic] OK：左声道有信号，接线正确
```

**判读表**：

| 现象 | 含义 |
|---|---|
| `引脚组合：PB12/...` + `OK` | ✅ 飞线成功，主线通了 |
| `引脚组合：PB9/PB10/PC3` + `OK` | ✅ 2×9 通了（备用脚）|
| `两套引脚都没数据` | 供电或 SD 线问题 |
| `PLLI2S 起振超时` | 时钟问题（不太可能）|
| `读取超时` | CK 完全没波形（线没通）|

## 五、给工作室的一句话总结

> 三件事：① 2×9 的连锡清干净；② 左侧 4P 焊母座；③ 扩展板背面 PB12/PB13/PB15 各飞一根线并贴标签。
> 全程用助焊剂，焊完用万用表测通断和短路。
